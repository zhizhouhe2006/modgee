# Bird habitat groups

A two-column data frame read from the supplied birds_groups.csv. The
columns contain species identifiers and habitat-group labels.

## Usage

``` r
example_groups
```

## Format

A data frame.

## Source

Maintainer-provided birds_matrix.csv and birds_groups.csv. Verify
original data attribution and redistribution terms before public
release.

## Usage Examples


    head(example_groups)
