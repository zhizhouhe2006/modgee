# Precomputed grouped MODGEE bootstrap example

Generated by data-raw/example_bootstrap_result.R before installation.
Uses example_M, example_groups, reference group "primary + old
secondary", seed 123, ten scheduled replicates and CI 0.95. Ten
replicates demonstrate the interface, not stable statistical inference.

## Usage

``` r
example_bootstrap_result
```

## Format

A fit_modgee result list with a bootstrap component containing settings,
status, summary, curve, group_results, diagnostics and replicates.

## Details

The checkpoint path is NULL for portability. Loading the object never
runs bootstrap. Inspect bootstrap\$status for the actual success count.
This object supplies input to future plot_modgee interval examples.

## Usage Examples


    example_bootstrap_result$bootstrap$status
    head(example_bootstrap_result$bootstrap$curve)
    plot_modgee(example_bootstrap_result)
