# Fitted ungrouped example model

A complete result list computed with fit_modgee(M = example_M) after
set.seed(123). The object is stored with the package; loading it does
not refit the model. See fit_modgee for the output fields.

## Usage

``` r
example_result
```

## Format

A fitted MODGEE result list.

## Source

Maintainer-provided birds_matrix.csv and birds_groups.csv. Verify
original data attribution and redistribution terms before public
release.

## Usage Examples


    example_result$summary
